# Monster racers — final four

This round completes the twelve-racer concept roster. The supplied composite sheet has been preserved and split into four individual 2×2 model-reference sheets. The crops are derived from the user's image; no visual content was regenerated or altered.

Keep the four monsters and their vehicles as separate editable systems. Reuse the gameplay interfaces from the first eight—vehicle root, seat socket, steering input, wheel pivots, VFX sockets and controller—but keep these visible architectures unique.
